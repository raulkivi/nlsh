# Security Policy

## Supported versions
Only the latest release receives security fixes.

## Reporting a vulnerability
Report vulnerabilities privately through [GitHub private vulnerability reporting](https://github.com/raulkivi/nlsh/security/advisories/new). Do not open a public issue.

Include:
- affected version or commit
- steps to reproduce or a proof of concept
- impact as you understand it

## What to expect
- Acknowledgement within 7 days.
- An assessment and, if confirmed, a fix plan within 30 days.
- Credit in the advisory unless you ask otherwise.

This is a personal project maintained on a best-effort basis.
